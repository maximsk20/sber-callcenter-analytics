# Contact Center Analytics & Quality Control Pipeline

Пайплайн для анализа данных контактных центров, автоматизированного поиска ошибок операторов и формирования аналитических выборок.

## Стек технологий
* **Python 3.10+**: Pandas, NumPy
* **SQL**: PostgreSQL / Greenplum (оконные функции ROW_NUMBER, LAG, CTE, временные таблицы)
* **Инфраструктура**: Docker Compose, Git

## Реализованная бизнес-логика
1. **Генерация репрезентативного датасета** (`data/generate_calls.py`): симуляция 25 000+ звонков с нормальными распределениями длительностей и бизнес-аномалиями.
2. **Аналитический пайплайн** (`src/analytics_pipeline.py`):
* **Детекция ошибок (`np.where`)**: выявление фиктивных закрытий звонков (< 10 сек со статусом resolved).
* **Анализ отклонений (`transform`)**: сравнение времени разговора со средними показателями по оператору.
* **Накопительная динамика (`cumsum`)**: расчет хронометража смены.
* **Сводные матрицы (`unstack`)**: кросс-таблицы распределения статусов звонков по отделам.
* **Фильтрация и срезы (`.loc`, `.iloc`)**: выделение групп риска операторов.
* **Парсинг тегов (`str.split`, `str.join`)**: структурирование логов обращений.
3. **SQL-аналитика** (`sql/analytics.sql`): расчет скользящих средних, ранжирование через оконные функции и изоляция выборок во временные таблицы.

## Как запустить проект локально

1. Развернуть PostgreSQL в Docker:
docker compose up -d

2. Установить зависимости:
pip install -r requirements.txt

3. Сгенерировать данные:
python data/generate_calls.py

4. Запустить аналитический пайплайн:
python src/analytics_pipeline.py
